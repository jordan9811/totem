## What it found

- Gate 1's suite found the import route treated `!result.mode` as refusal, but a successful pack import deliberately returns `mode: null` plus `pack`, so every legitimate pack import 422'd; fixed to `!mode && !pack`. {cite: notes/reports/REPORT-B.md > "GATE 1 — Network-state filter packs — CLOSED (5/5)"}
- Gate 2 found that three-decimal rounding after 2dp turned the rate card itself into a bug (0.015 -> 0.02, a silent 33% repricing). {cite: notes/reports/REPORT-B.md > "GATE 2 — Crosspost composer — CLOSED (6/6)"}
- Gate 2 found the composer's cost estimate had no sequence guard, so under 200-1500ms mock latency an earlier draft's estimate could land after the current one and show a stale price; fixed by dropping out-of-order responses and showing "Estimating cost..." while a fetch is in flight. {cite: notes/reports/REPORT-B.md > "GATE 2 — Crosspost composer — CLOSED (6/6)"}
- A killed `next start` left a zombie server owning :3000 for ~40 minutes; the replacement start died with EADDRINUSE inside a backgrounded subshell, so every "post-fix" test run was actually hitting the old build, tipped off by an impossible 422-with-empty-violations response shape. {cite: notes/reports/REPORT-B.md > "Ops lesson (cost: ~40 minutes)"}
- Gate 0 caught the cast route asserting edges as the SEED viewer while stamping casts with the SESSION persona — described as the third sighting of the two-identity-universes trap. {cite: notes/reports/REPORT-B.md > "GATE 0 — Cleanup — IN PROGRESS"}
- Sweep set 1 found run1 m3 check 13 was an INFRA classification (`mode.create` hit the 2% synthetic failure past the test's retries), correctly classified as could-not-test with zero product failures. {cite: notes/reports/REPORT-B.md > "FINAL VERIFICATION LOG"}
- Sweep set 1 found run1 a2 check 6's shelf-count assertion had gone stale a second time ("3 algo cards" predated Gate 1 filing the seeded pack card on the same shelf); fixed to 4 with the pack card asserted by name. {cite: notes/reports/REPORT-B.md > "FINAL VERIFICATION LOG"}
- Stopping a background driver was found to kill only the top shell — the sweep bash, npm wrapper, and node suite it spawned kept running and advanced two suites past the kill; orphan checks after any driver stop must now walk the whole process tree. {cite: notes/reports/REPORT-B.md > "Ops lesson (harness)"}
- Sweep set 2 run 2 found m3 check 14 failing with a TypeError from an unretried `mode.create` drawing the 2% synthetic failure — the same root cause as set 1's check-13 INFRA, now failing uncleanly instead of clean. {cite: notes/reports/REPORT-B.md > "FINAL VERIFICATION LOG"}
- Sweep set 2 run 2 found a real bug: b2 check 5 saw the overlapping viewer see 2 copies of the collapse subject, because `resetSeed` never cleared local casts — `data.ts`'s fixture store (`extraCasts`) is untouched by `resetState`, so composer-made casts accumulate for the server process's lifetime across every reset; described as the first check sensitive to process-lifetime accumulation. {cite: notes/reports/REPORT-B.md > "FINAL VERIFICATION LOG"}
- Fixes applied and proven in isolation: `resetState` now clears the render layer's fixture store via `resetLocalStore()`, and `accept-m3` gained a `retryApi()` helper wrapping all four unretried mode-create sites. {cite: notes/reports/REPORT-B.md > "FINAL VERIFICATION LOG"}

## Judgment calls

- `notes/design/roadmap-v4.md` still does not exist; same situation as Tier A, same resolution — the prompt fully specifies every gate and is treated as the operative spec. {cite: notes/reports/REPORT-B.md > "Judgment calls made before building"}
- "Enforce in the validator" for refutation authorship is read as the evaluation layer (`declareEdge`/`holdsStanding`), not the phase-1 validator service which has no knowledge of edges, because the evaluation layer is the place a hostile client cannot route around. {cite: notes/reports/REPORT-B.md > "Judgment calls made before building"}
- The starvation fix is per-TENANT, not per-type, because community notes and curator annotations share the `correction` card type and a per-type floor can't distinguish them — exactly how Tier A's starvation happened. {cite: notes/reports/REPORT-B.md > "Judgment calls made before building"}
- One action-switched route (`/api/market/infofi`) was used instead of four route files, since four thin features over one ledger read better as one surface. {cite: notes/reports/REPORT-B.md > "Judgment calls (Gate 3)"}
- Tip-epoch likes resolve at close (seeded count plus the viewer's own like), not at tip time, so the split rewards how the post performed and removes a caller-supplied-likes cheat seam that was in the first draft. {cite: notes/reports/REPORT-B.md > "Judgment calls (Gate 3)"}
- `curatorFeeds` and `annotationDrafts` were both switched to persist, since issued annotations are user-made state and persisted state wins over seed on boot, same as every other namespace. {cite: notes/reports/REPORT-B.md > "GATE 4 — Curator issuance — CLOSED (7/7)"}
