This section is the owner's. Pages here are written by hand, or in GitBook's editor, and **no script
touches them**: `npm run docs:generate` rewrites only the pages that carry a generated banner, and
`npm run docs:summary` only ever appends an unlisted page to the table of contents — it never
reorders, rewrites or deletes a line.

Use it for anything that is not a report: decisions taken outside a pass, questions to come back to,
notes from testers. `npm run docs:check` still applies, so a page that makes a privacy claim has to
cite the document it comes from, or carry the `uncited-ok` marker this page uses.
