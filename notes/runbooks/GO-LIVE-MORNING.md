Run these from the repo folder, in order, in a **standalone Windows PowerShell window**: Windows Terminal or the PowerShell app, not an IDE terminal, not the Claude app's terminal panel, and no screen sharing or recording (step 1 shows the 24 words once). `powershell ...` always starts Windows PowerShell 5.1. Each script re-checks everything and skips what is already done, so running it again is always safe. Add `-WhatIf` first to print every command without running any. **[$]** spends money · **[S]** you handle a secret · **[P]** publishes on Farcaster. Full rationale: `notes/runbooks/GO-LIVE-FARCASTER.md` (GL).

1. **[S] The private owner service** (about 10 min; $0 beyond the Railway usage already running):
   `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\owner\arm-owner-service.ps1`
   **The first run stops once, on purpose:** `FC_TEST_CUSTODY_PRIVATE_KEY` is still in `.env.local`. Paste the lines it prints between `--- copy from here ---` and `--- to here ---` (they print nothing), then run the same command again (GL (b) step 1). It prints the `Remove-Item` line for the leftover `.env.local` copy; run it once the script has got past preflight.
   It then waits for you twice. First, to **save the new passphrase in your password manager**: it is put on the clipboard, kept out of clipboard history and cloud sync, and never shown; press Enter when it is saved, and the clipboard is emptied. Second, **type `PAPER`**, write the 24 words on paper, and press Enter. The screen and its scrollback are then cleared: scroll up to check, and close the window if a word is still there. It ends with writes armed. Options: `-LiveContent` (live feeds, costs credits) and `-ViewerFid <your main account's fid>`. **Pass `-ViewerFid`:** without it Totem can't tell which Farcaster account is your main one, so it refuses a persona's replies, likes, recasts, follows and @mentions (plain posts still go out).
2. **[S] Sign in once on each device**: open the owner app's `/home` (the script prints the address) on your laptop AND on your iPhone. Sign in with the passphrase from your password manager (save it there with the username `owner` and the owner app's address as the website, in a password manager your iPhone also has, so the phone fills it in). Then tap **Add Face ID / fingerprint for this device** when it offers (on Windows it is Windows Hello). After that each device signs in with one tap, 30 days at a time; the 24 words are never needed to sign in. On a computer that is not yours, tap **This isn't my device** instead (it signs you out within 2 hours). **Lost a device?** Settings > Security > **Lost this device?** next to its Face ID / fingerprint: that removes it AND signs out every device (for an iPhone, also erase it in Find My). A lost device that never added Face ID / fingerprint: **Sign out everywhere**. (The Face ID offer appears once Claude's morning deploy is on the service; until then the passphrase alone signs you in.)
3. **[$] [P] One Farcaster account per persona** (about $0.35 to $0.90 of ETH each from the Neynar app wallet, which cannot be withdrawn; hours apart; only after step 0 (a)): with no persona yet (the service hides the demo world, so it starts empty), first create one in Settings › Account & Personas (`/settings/account`, "Create your first persona"), then fork it at `/settings/identity/fork` into a new PUBLIC persona; copy its `p_...` id, then
   `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\owner\acquire-fid.ps1 -PersonaId p_PASTE_THE_ID`
   Before the dry run it tells you who registers the account onchain: the App Wallet behind `NEYNAR_WALLET_ID`, your own wallet, not Neynar. That wallet registered the Totem-named test account and the fids beside it (3348983 to 3348991) in one burst, so a persona made through it sits next to the test account onchain for good (same sender, minutes apart, a next-door fid): the sibling link from step 0 (a). Type `SIBLINGS` to go ahead with that wallet anyway. To avoid it, create a fresh Neynar app with its own App Wallet that has never touched the test account, put that app's key in `.env.local` as `NEYNAR_API_KEY`, and run `acquire-fid.ps1 -PersonaId p_... -WalletId <that wallet id>`; it then asks you to type `FRESH` (your word that the wallet never registered or funded the test account or a persona; the personas you make through it still share it with each other). Wallet ids are only ever shown by their last 4 characters. Then it shows the cost sheet (a dry run, nothing billable). Type `SPEND` to create the account, then `YES` to disarm account creation. If this machine has no record of the 24 words, it first asks `Are the 24 words on paper? Type YES`. The persona must be one your owner session can act as: if the dry run aborts with 403 out_of_scope, switch to that persona in the owner app and run again. Never put `FID_ACQUIRE_CONFIRM` in `.env.local`; the script refuses to run while it is there.

A lost device that never added Face ID / fingerprint: **Sign out everywhere**. (A new passphrase also signs out every device and removes every Face ID / fingerprint sign-in.)
